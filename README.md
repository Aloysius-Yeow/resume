# Aloysius Yeow Yee Jian: Resume and Portfolio Website

This repository contains the source files for the personal resume and portfolio website of Aloysius Yeow Yee Jian, a Year 2 student in the Diploma in Computing (Cybersecurity Specialisation) at Nanyang Polytechnic, Singapore.

Live site: https://aloysius-yeow.github.io/resume/

## Purpose

The website presents my education, work experience, skills, training, leadership activities and academic project work for recruiters and internship coordinators.

## Contents

- `index.html`: page content and structure
- `styles.css`: styling, including dark and light themes
- `script.js`: mobile navigation, theme preference and the contact form
- `profile.jpg`: profile photo
- `resume.pdf`: downloadable resume

## Deployment

The website is hosted using GitHub Pages. Link as follows: https://aloysius-yeow.github.io/resume/

## Content notes

- The Web Development Project is an academic group project completed at Nanyang Polytechnic. It is presented as coursework, not professional experience.
- The skills listed reflect coursework, training and project exposure.
- The credentials listed are completed courses, a training badge and a participation certificate. They are not professional certifications.

## Privacy

- The contact form opens a prefilled email draft in the visitor's email application. The website does not send, collect or store messages.
- Fonts are loaded from Google Fonts, a third-party service.
- The website is publicly accessible and shows my email address, LinkedIn profile, GitHub profile and credential identifiers.
